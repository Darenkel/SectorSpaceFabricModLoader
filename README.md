Use VSCode or Intellij IDEA, personally I'm using IDEA.
To build run the gradle app:jar
Place app.jar into game directory or wherever to make it work.

To mod on this fork:
0. Install the loader JAR and place it somewhere.
1. Start loader JAR once so it generates mods folder and config.
2. Place mod JARs into mods folder.
3. Restart loader JAR to auto-generate entries in config, or manually add them.
4. Set true or false for mods you want loaded on next run.
5. Start load JAR and play modded game.
